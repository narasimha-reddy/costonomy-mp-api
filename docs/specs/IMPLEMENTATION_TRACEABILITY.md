# Implementation Traceability

This document is the contract for proving that requirements are implemented.

## 1. Status values

Use:

- `NOT_STARTED`
- `IN_PROGRESS`
- `IMPLEMENTED`
- `TESTED`
- `BLOCKED`
- `DEFERRED`

`TESTED` means a named test exists for the requirement; it does **not** mean the code is deployed or visible in a mobile build.
Those are separate claims, recorded for delivery in §2a. A "pending" in the Mobile column is only as current as the
mobile audit dated in §2a.
